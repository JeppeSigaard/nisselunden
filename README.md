# Nisselunden

Bevægelsessensor til nisseudstillingen i Rørvig. En gammel mobiltelefon bruger sit kamera til at opdage forbipasserende og spiller nissemusik.

## Brug

1. Åbn siden i telefonens browser (adressen skal starte med `https`).
2. Tryk **Start** og giv lov til kameraet.
3. Slå felter fra, hvor der er blinkende lys eller trafik, og stil grænsen, så måleren kun går over stregen, når nogen går forbi.

Telefonen skal sidde i lader med lyden skruet op og automatisk skærmlås slået fra. Efter første besøg virker siden uden internet. Hvis telefonen genstarter, skal der trykkes Start igen.

## Musik

`musik.mp3` er en pladsholder. Udskift filen med den rigtige musik under samme navn.

## Filer

- `index.html`, `app.js` – siden og sensoren
- `sw.js` – gemmer siden på telefonen til brug uden net
- `vaagen.mp4` – lydløs video, der holder skærmen tændt på ældre browsere
